# Tutorials

The tutorials are kept in the repository, next to the input files they use.
Follow them in a copy of the tutorial directory, because the commands write
many files next to the inputs.

## Ligand FEP (QligFEP)

| Tutorial | What it covers |
|---|---|
| {repo}`Tyk2 <tutorials/Tyk2/README.md>` | Relative binding free energies for a ligand series, from ligand parameters and the perturbation network to submission and analysis |
| {repo}`Tyk2, non-equilibrium <tutorials/Tyk2/neq2/README.md>` | The same series with the non-equilibrium switching protocol (NEQ²) |
| {repo}`CCR2 <tutorials/CCR2/README.md>` | Aligning a ligand series to a reference ligand before setting up the calculations |

Background: [QligFEP workflow](../qligfep/workflow.md).
